# BrokenRanks Settings

A single-file page listing the Broken Ranks key bindings — Windows, Combat, Chat, Map, Other and Gestures — with every key rebindable.

Open `index.html` in a browser. Click a key slot and press the key you want; modifiers alone (Shift, Ctrl, Alt) bind on release. Right-click a slot to clear it. A key used twice in one section is outlined red. Changes are saved in that browser's local storage; **Reset to defaults** restores the in-game defaults, **Copy as text** copies the full list.

No build, no dependencies beyond a Google Fonts stylesheet.
